# Development and Design Rules

1. Use semantic HTML tags and accessible labels.
2. Include `alt` text for all images.
3. Keep CSS and JS lightweight with no unnecessary dependencies.
4. Use kebab-case for project page filenames in `/projects`.
5. Keep contact flow resilient and fail gracefully.
6. Only the owner (`monaimabdel119@gmail.com`) can authorize backend actions or make project changes.
7. Non-owner users can only watch/browse the portfolio in read-only mode.
8. Every project page must present: context, implementation highlights, and outcome.
