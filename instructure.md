# Project Structure Blueprint

- `/index.html`: Portfolio landing page with project list and pagination.
- `/projects/`: Individual project pages in SEO-friendly kebab-case names.
- `/assets/css`: Global and component styles.
- `/assets/js`: UI and API interaction scripts.
- `/assets/img`: Optimized images.
- `/admin.html`: Authentication status and owner-only access panel.
- `/app.py`: Backend API, OAuth flow, and Google service integrations.

## Governance

- Project edits are owner-only. External users are view-only.
- Each project page must include a concise presentation section so visitors can understand the value quickly.
